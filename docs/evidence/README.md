# Evidence: 2025-03-14 12Z, ours | archived NAM | MRMS

Each image puts three panels side by side at the same valid time: woof-nam (native start from the
NAM 12Z analysis, all physics on), the archived operational NAM 12 km forecast of the same cycle,
and MRMS observed composite reflectivity. The panels are the Rust renderer's maps, cropped and
placed side by side; nothing was re-rendered.

- refc: composite reflectivity, the same 10-85 dBZ colour scale on both model panels.
- d2m / t2m: 2 m dewpoint and 2 m temperature.
- mslp: ours only; the archived NAM set has no forecast MSLP map, so that slot is marked missing.

At +24 h, like the NAM, ours wraps the comma head over the upper Midwest. Its trailing line sits
too far west (Indiana to the lower Mississippi) and is weaker and more broken than the NAM's, and
neither model has MRMS's second band across Mississippi and Alabama.
